# 04 Physical Layer

This folder covers the Physical Layer, where data is represented as signals and transmitted over physical media.

## Contents

1. [Data transmission](1. Data transmission.md)
2. [Bandwidth](2. Bandwidth.md)
3. [Transmission media and Wireless transmission](3. Transmission media and Wireless transmission.md)

## Learning Outcomes

By the end of this section, you should be able to:

- explain how bits are turned into signals and sent across links
- distinguish transmission types, modes, and timing methods
- calculate and reason about bandwidth, throughput, and related limits
- compare wired and wireless transmission media with real-world tradeoffs
- choose suitable media based on distance, speed, cost, and environment
