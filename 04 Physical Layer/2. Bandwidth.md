# Bandwidth

Bandwidth is one of the most important concepts in networking because it defines the capacity of a communication channel.

## What Bandwidth Means

The term bandwidth is used in two related ways:

### 1) Frequency Bandwidth (Analog View)

- Difference between highest and lowest frequency a channel can pass.
- Measured in hertz (Hz).

Formula:

Bandwidth = f_high - f_low

Example:

- A channel that carries 1 MHz to 5 MHz has 4 MHz bandwidth.

### 2) Data Bandwidth / Link Capacity (Digital View)

- Maximum amount of data that can be transferred per second.
- Measured in bits per second (bps).

Examples:

- 100 Mbps Ethernet
- 1 Gbps fiber link

## Units and Scale

- bps = bits per second
- Kbps = 10^3 bps
- Mbps = 10^6 bps
- Gbps = 10^9 bps
- Tbps = 10^12 bps

Note: storage units use bytes (B), where 1 byte = 8 bits.

## Bandwidth vs Throughput vs Goodput

### Bandwidth

- Theoretical maximum capacity of the link.

### Throughput

- Actual rate at which data is transferred.
- Usually lower than bandwidth due to protocol overhead, congestion, and errors.

### Goodput

- Useful application data rate only.
- Excludes headers, retransmissions, and control packets.

Relationship:

goodput <= throughput <= bandwidth

## Why Actual Speed Is Lower Than Advertised

Common reasons:

- protocol headers and acknowledgments
- retransmissions due to errors
- congestion and queueing delays
- shared medium contention
- hardware limitations

## Channel Capacity Limits

Two classic laws explain limits on data rate.

### Nyquist Bit Rate (Noiseless Channel)

For a noiseless channel with bandwidth B and M signal levels:

Maximum data rate = 2B \* log2(M)

Implications:

- increasing bandwidth increases possible bit rate
- increasing signal levels increases bits per symbol

### Shannon Capacity (Noisy Channel)

For bandwidth B and signal-to-noise ratio S/N:

C = B \* log2(1 + S/N)

Where:

- C is maximum achievable data rate
- S/N is linear ratio (not in dB)

Implications:

- both bandwidth and SNR affect achievable capacity
- no coding/modulation can exceed this theoretical limit

## Bandwidth-Delay Product (BDP)

BDP shows how much data can be in transit before acknowledgment returns.

Formula:

BDP = bandwidth \* round-trip time (RTT)

Example:

- 100 Mbps link, RTT = 50 ms
- BDP = 100,000,000 \* 0.05 = 5,000,000 bits = 625,000 bytes

Meaning:

- sender needs at least this much outstanding data for full utilization.

## Symmetric vs Asymmetric Bandwidth

### Symmetric

- Upload and download rates are equal.
- Common in enterprise leased lines and some fiber plans.

### Asymmetric

- Download speed is higher than upload speed.
- Common in consumer broadband.

## Dedicated vs Shared Bandwidth

### Dedicated Bandwidth

- Reserved for one user or link.
- Predictable performance.
- Higher cost.

### Shared Bandwidth

- Multiple users share the same capacity.
- Can vary with network load.
- Common in Wi-Fi and ISP access networks.

## Spectral Efficiency

Spectral efficiency measures how efficiently bandwidth is used.

Formula:

Spectral efficiency = data rate / channel bandwidth (bits/s/Hz)

Higher-order modulation and better coding improve spectral efficiency, but they often require better SNR.

## Bandwidth Management in Networks

Typical techniques:

- Traffic shaping: smooths traffic to a target rate.
- Policing: drops or marks traffic above allowed rate.
- QoS prioritization: gives priority to delay-sensitive traffic.
- Load balancing: distributes traffic across multiple links.
- Compression and caching: reduce repetitive traffic.

## Practical Examples

### Example 1: Home Internet Plan

- Plan says 200 Mbps.
- Speed test shows 145 Mbps.
- This is normal due to protocol overhead and path conditions.

### Example 2: Video Streaming

- 4K stream may need 15-25 Mbps goodput.
- If available throughput drops below requirement, buffering occurs.

### Example 3: File Transfer Time

If file size is 800 MB and effective throughput is 80 Mbps:

1. Convert 800 MB to megabits: 800 \* 8 = 6400 Mb
2. Time = data / rate = 6400 / 80 = 80 seconds

## Common Misconceptions

- More bandwidth always means lower latency. (Not always true.)
- Throughput and bandwidth are the same. (They are different.)
- High bandwidth guarantees high application performance. (Depends on loss, latency, jitter, and server behavior too.)

## Quick Summary

Bandwidth is channel capacity, not guaranteed delivered speed. Real performance depends on throughput, goodput, latency, packet loss, and how efficiently protocols use available capacity.
