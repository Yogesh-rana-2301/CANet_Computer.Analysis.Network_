# OSI Model Overview

The OSI (Open Systems Interconnection) model is a 7-layer framework used to understand how data moves across a network.

## Why it matters

- Breaks networking into clear layers.
- Makes troubleshooting easier.
- Helps compare protocols and devices by function.

## The 7 layers (top to bottom)

7. Application

6. Presentation

5. Session

4. Transport

3. Network

2. Data Link

1. Physical


## Simple data flow idea

- Sender data moves from Layer 7 down to Layer 1.
- Receiver data moves from Layer 1 up to Layer 7.

## Quick memory line

- Top to bottom: App, Pres, Sess, Trans, Net, Data Link, Physical.
- Bottom to top: Physical, Data Link, Network, Transport, Session, Presentation, Application.
