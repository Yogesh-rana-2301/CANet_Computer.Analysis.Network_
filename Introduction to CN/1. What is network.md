# What Is a Network?

A network is a group of two or more devices connected so they can exchange data and share resources.

Examples of devices in a network:

- Laptops
- Mobile phones
- Servers
- Printers
- Routers and switches
- IoT devices (smart cameras, sensors, smart TVs)

## Why Networks Are Important

Networks make modern computing practical by enabling:

- Communication (email, chat, video calls)
- Resource sharing (printers, files, storage)
- Centralized services (authentication, databases, backups)
- Internet access
- Scalable applications (cloud systems, microservices)

## Basic Components of a Network

- Sender: device that originates data
- Receiver: device that receives data
- Medium: path used to carry data (copper, fiber, wireless)
- Protocol: rules for communication (TCP/IP, HTTP, DNS)
- Addressing: identity system to reach devices (IP and MAC addresses)
- Network devices: switch, router, firewall, access point

## How Data Moves in a Network (Simple Flow)

1. Application creates data (for example, browser request).
2. Data is split and wrapped into network units (packets/frames).
3. Source device sends data through a network interface.
4. Switches/routers forward it toward destination.
5. Destination receives and reassembles data.
6. Application processes data and sends a response.

## Key Characteristics of a Good Network

- Performance: high throughput, low latency
- Reliability: low downtime, fault tolerance
- Security: confidentiality, integrity, access control
- Scalability: supports growth without major redesign
- Manageability: easy monitoring and troubleshooting

## Real-World Example

When you open a website:

- DNS translates domain name to IP address.
- Your device connects to the server.
- Data flows through multiple networks and routers.
- Server sends page content back to your browser.

## Common Interview One-Liner

A network is an interconnected system of devices that communicate using standardized protocols to share data, services, and resources.
