# Hub, Switch, and Router

These are core network devices with different roles.

## 1. Hub

A hub is a basic Layer 1 (physical layer) device.

How it works:

- Receives an incoming signal
- Repeats it to all ports

Characteristics:

- No traffic intelligence
- No MAC table
- Creates one large collision domain
- Low security and poor efficiency

Status today:

- Mostly obsolete in modern networks

## 2. Switch

A switch is mainly a Layer 2 device (some are Layer 3 capable).

How it works:

- Learns source MAC addresses
- Builds MAC table (MAC-to-port mapping)
- Forwards frame only to destination port when known

Characteristics:

- Much better performance than hub
- Each port is its own collision domain
- Supports VLAN segmentation in managed switches

Use case:

- Standard device for connecting endpoints in LAN

## 3. Router

A router is a Layer 3 device.

How it works:

- Uses IP addresses and routing table
- Forwards packets between different networks/subnets
- Selects path based on routes

Common functions:

- Inter-subnet routing
- Internet connectivity
- NAT
- ACL-based filtering

Use case:

- Connects LAN to WAN/internet
- Connects multiple internal subnets

## Side-by-Side Comparison

| Feature           | Hub             | Switch                  | Router                     |
| ----------------- | --------------- | ----------------------- | -------------------------- |
| OSI layer         | Layer 1         | Layer 2 (or multilayer) | Layer 3                    |
| Forwards by       | Signal repeat   | MAC address             | IP address                 |
| Collision domains | Single shared   | One per port            | One per interface          |
| Broadcast domain  | Single          | Single per VLAN         | Separate by default        |
| Intelligence      | None            | Medium                  | High                       |
| Typical role      | Legacy repeater | LAN access/connectivity | Network-to-network routing |

## Simple Analogy

- Hub: person shouting message to everyone in a room
- Switch: receptionist sending message to the right desk
- Router: traffic officer directing vehicles to different roads/cities

## Interview One-Liner

Hub broadcasts blindly, switch forwards intelligently within a LAN, and router connects different networks using IP routing.
