# Nodes and Links

Nodes and links are the most basic building blocks of any network graph.

## What Is a Node?

A node is any addressable or active point in a network that can send, receive, or forward data.

Examples of nodes:

- End devices: PCs, phones, servers, printers
- Network devices: switches, routers, firewalls
- Virtual entities: VMs, containers, pods (in logical network views)

Node roles:

- Source node (originates data)
- Destination node (receives data)
- Intermediate node (forwards data)

## What Is a Link?

A link is the communication path between two nodes.

Types of links by medium:

- Wired: twisted pair, coaxial, fiber
- Wireless: Wi-Fi, microwave, cellular, satellite

Types of links by direction:

- Simplex: one-way only
- Half-duplex: both ways, but one direction at a time
- Full-duplex: both directions simultaneously

## Link Properties That Affect Performance

- Bandwidth: maximum data carrying capacity
- Latency: transmission delay
- Jitter: variation in delay
- Packet loss/error rate: reliability indicator
- Availability: uptime and stability

## Relationship Between Nodes and Links

A network can be viewed as a graph:

- Nodes are vertices
- Links are edges

Routing and switching decisions are effectively path selections across this graph.

## Practical Examples

- Home network:
  - Nodes: phone, laptop, router, smart TV
  - Links: Wi-Fi and Ethernet

- Data center:
  - Nodes: servers, top-of-rack switches, core routers
  - Links: high-speed fiber and redundant paths

## Why This Topic Matters in Interviews

Many advanced concepts are built on nodes and links:

- Topology design
- Routing path selection
- Redundancy and failover
- Capacity planning
- Fault analysis

## Interview One-Liner

Nodes are communication endpoints or forwarding devices, and links are the wired or wireless paths that connect them into a functioning network.
